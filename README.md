# Maple Plain Assessment Project

**Community data. Shared resources. Informed property owners.**

A community-created resource for Town of Maple Plain property owners in the Cumberland, Wisconsin area reviewing the 2026 property reassessment.

## What the site includes

- Current posted 2026 Open Book and Board of Review dates
- Plain-language Wisconsin assessment challenge process
- Assessment increase calculator
- Board of Review evidence checklist
- Official Wisconsin DOR forms and resources
- Town, assessor, county, and DOR contact information
- Community assessment submission form powered by Netlify Forms
- Information on post-BOR appeals and Wisconsin's § 70.75 reassessment petition process

## Deployment

This is a static HTML/CSS/JavaScript site intended for Netlify.

1. Import this GitHub repository into Netlify.
2. No build command is required.
3. Publish directory is `.` and is also defined in `netlify.toml`.
4. In Netlify, enable **Forms > Form detection** and redeploy once so the `assessment-submission` form is registered.
5. Test with a real submission and verify it appears in Netlify Forms.

## Community data privacy

The public site asks owners to submit assessment information voluntarily. Names, email addresses, property addresses, and parcel numbers are intended for private verification only. Aggregate statistics can be published after review. Do not scrape or republish Barron County tax data; the County portal publishes terms limiting redistribution of its data.
